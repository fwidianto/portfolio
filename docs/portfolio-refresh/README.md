# Portfolio Refresh Planning

This folder contains the planning documents for refreshing the public portfolio repository before changing the live GitHub Pages site.

The goal is to keep `main` stable while preparing a stronger public-facing portfolio that reflects the latest progress in ERP analytics, Odoo reporting, AI-assisted development, automation, and career positioning.

## Branch

Working branch: `portfolio-refresh-plan`

## Why this exists

The current public portfolio is functional, but it now underrepresents the latest work:

- Odoo Analytics / `dashboard-odoo`
- SQL-based ERP reporting and data modeling
- AI-assisted development workflow using ChatGPT and Codex
- AI ERP dashboard deployment
- PersonalOS / CareerOS concept and AI handoff workflow
- Updated career positioning toward analytics, business intelligence, FP&A, strategy, and operations analytics roles

## Planning documents

| File | Purpose |
| --- | --- |
| `PORTFOLIO_REFRESH_PLAN.md` | Main strategy, content changes, and phased update plan. |
| `CODEX_HANDOFF.md` | Implementation brief for Codex to update the portfolio safely. |
| `PUBLIC_CONTENT_BOUNDARIES.md` | What can be public, what should stay private, and how to reference PersonalOS safely. |

## Working principle

PersonalOS is the private source of truth. The portfolio is the public showcase.

Do not copy private notes, job-search details, personal reflections, credentials, internal company-sensitive details, or private data from PersonalOS into the public portfolio.

Only publish clean, recruiter-safe summaries, project case studies, screenshots, and high-level architecture explanations.
