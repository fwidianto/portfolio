# Portfolio Working Principles

Status: Active source of truth

This document defines the working traits the portfolio should reveal through evidence. These are not meant to become a standalone homepage section. They should guide copy, case-study structure, visual metaphors, and feature selection.

## Core Working Identity

Fauzan is not simply trying to look like a dashboard builder or developer.

The stronger story is:

```text
Curious, system-oriented, business-first, and practical.
```

The portfolio should show someone who learns by building tools that make messy business operations easier to understand.

## Working Traits to Reveal

| Trait | What it means | Portfolio expression |
| --- | --- | --- |
| Curiosity | Questions trigger learning and projects. | Capability Graph, Thinking Lab, current explorations. |
| Systems thinking | Understand relationships before building outputs. | Process maps, review signals, data-flow explanations. |
| Learning by building | Tools are learned through real problems. | Case studies, project evolution, currently-building notes. |
| Iteration | Work improves through review and refinement. | Changelogs, current focus, documented decisions. |
| Business-first judgment | Business questions lead technology decisions. | Problem-first project structure and management visibility framing. |
| Documentation discipline | Reasoning is preserved for future handoff. | Source docs, page plans, public-safe case notes. |
| Initiative | Ideas are noticed before they become projects. | Curated Thinking Lab explorations. |

## Homepage Implication

Future homepage development should ask:

```text
What part of Fauzan's thinking does this section reveal?
```

The strongest homepage pillars are:

1. Capability Graph
2. Thinking Lab
3. Currently Building
4. Flagship Case Study

## Project Page Implication

Project pages should show:

- the problem,
- the business context,
- the messy source reality,
- the reasoning process,
- the validation logic,
- the output,
- the lesson learned,
- the public-safe limitation.

The Odoo ERP Analytics case study is the reference proof.

## Design Filter

Before adding something to the portfolio, check whether it reflects at least one of these:

- curiosity,
- systems thinking,
- learning by building,
- iteration,
- business-first judgment,
- documentation discipline,
- initiative.

If it does not, it is likely decoration.
