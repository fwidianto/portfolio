Status: Active source index

This folder defines design-level guidance for the portfolio. It supports the core philosophy without duplicating it.

Read [../core/portfolio-design-philosophy.md](../core/portfolio-design-philosophy.md) before using these documents.

## Documents

| Document | Purpose |

## When to Read

Read this folder before changing homepage flow, navigation structure, public-facing hierarchy, tone, or visual direction.

## What Should Not Be Placed Here

- Detailed implementation instructions.
- Full case-study content.
- Duplicate philosophy blocks.
- Component-level CSS decisions unless a future design-system task creates a dedicated document.
