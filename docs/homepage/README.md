Status: Active source index

This folder defines the future homepage experience. It is documentation only; it does not authorize implementation by itself.

## When to Read

Read this folder before designing or implementing homepage sections, navigation flow, homepage copy, homepage interaction behavior, or project-routing decisions.

## What Should Not Be Placed Here

- Core philosophy that belongs in `../core/`.
- Visual style rules that belong in `../design/`.
- Full case-study content that belongs in `../case-studies/`.
- Implementation notes for HTML, CSS, or JavaScript.

## Implementation Boundary

These documents define intent and structure only. Do not build the Capability Graph UI, Thinking Lab UI, or other homepage features until a future implementation task explicitly requests it.
