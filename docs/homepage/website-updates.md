# Homepage Website Updates

Status: Active maintenance rule

Website Updates is the public changelog for visible portfolio improvements.

It should show that the portfolio is actively maintained without making the site feel unfinished.

## Maintenance Rule

Every visible portfolio website update must also update both places:

- `index.html` compact Website Updates section: latest 3 updates
- `website-updates.html` full changelog: latest 10 updates

## What Counts

Update the changelog when visitors can see the change, such as homepage sections, project pages, case study pages, visible copy, layout improvements, navigation changes, or public portfolio evidence changes.

Do not update the public changelog for purely internal documentation changes unless the documentation is part of the public website experience.

## Style

Use calm, visitor-facing language.

Avoid raw commit messages and overly technical wording.

Do not duplicate the same update twice. If a follow-up is only visual polish of the same update, adjust the latest item instead of adding another duplicate item.
