# Homepage V1 Freeze

Status: Frozen / accepted checkpoint

Commit: `67cb782`
Commit message: `refactor: unify homepage headers and flagship project focus`

This document records the accepted homepage state after the homepage refinement work. Future sessions should treat this as the first checkpoint before proposing homepage changes.

## Frozen Positioning

The homepage public identity is:

```text
Analytical Systems Builder
```

Core positioning:

```text
From problems and data to system design, insights, and AI-powered workflows.
```

The portfolio should present Fauzan as someone who understands business and operations problems, structures data and process logic, and builds useful systems/workflows using ERP knowledge, dashboards, automation, and AI-assisted development.

The homepage should not present Fauzan as a pure software developer, generic dashboard builder, flashy AI engineer, or project inventory owner.

## Frozen Homepage Flow

The accepted homepage flow is:

```text
Hero
-> Professional Experience
-> Core Skills
-> Skill Development Curve
-> How I Think Through Problems
-> Flagship Project / Odoo ERP Analytics
-> Website Updates
-> Contact
```

Do not casually change this order.

## Frozen Section Decisions

### Hero

Frozen.

- Role/subtitle: `Analytical Systems Builder`
- Headline: `From problems and data to system design, insights, and AI-powered workflows.`
- Proof strip removed and should not be re-added.

### Professional Experience

Accepted.

The section should continue showing wide branded company cards with real company logos and concise experience narratives.

### Core Skills

Frozen as v1.

The section should remain a dynamic working path:

```text
Understand -> Structure -> Review -> Build
```

The bars show skill emphasis at each stage, not exact self-rating scores.

Allowed future changes are limited to bug fixes, accessibility improvements, responsive fixes, and minor outer header/spacing consistency.

### Skill Development Curve

Accepted as v1.

The section should complement Core Skills by showing how capability evolved over time. Do not redesign unless there is real visitor, recruiter, HR, or manager feedback that it is confusing or ineffective.

### How I Think Through Problems

Frozen as v1.

The accepted concept is the Problem-Solving Engine:

```text
Messy Inputs -> Thinking Engine -> Practical Outputs
```

Do not redesign this section. Only allow minor responsive, accessibility, spacing, or outer header consistency fixes.

### Flagship Project

Frozen direction.

The homepage project area should focus on one visible flagship project only:

```text
Odoo ERP Analytics
```

Supporting projects may remain in the repository or separate pages, but they should not be visible as a homepage project grid until they are ready to compete for attention on equal footing.

Homepage route line:

```text
Scattered ERP transactions -> reliable business logic -> management-ready views
```

CTA target:

```text
Projects/Odoo-ERP-Analytics.html
```

### Website Updates

Maintain the existing public changelog rule:

- homepage: exactly 3 visible update items
- `website-updates.html`: exactly 10 visible update items

Avoid duplicate noisy entries.

### Contact

May remain centered as the closing CTA.

## Header System Decision

Main narrative section headers should use a consistent editorial treatment and remain left-aligned:

- Professional Experience
- Core Skills
- Skill Development Curve
- How I Think Through Problems
- Flagship Project

Exceptions:

- Hero remains unchanged.
- Website Updates can keep its compact/special panel style.
- Contact can remain centered.

## Allowed Future Homepage Changes

Allowed:

- bug fixes
- accessibility fixes
- responsive fixes
- minor spacing adjustments
- factual content updates
- link updates
- changelog updates
- small copy improvements that do not change the accepted structure

Not allowed without explicit new strategy discussion:

- changing the homepage section order
- reintroducing a multi-project homepage grid
- re-adding the Hero proof strip
- redesigning Core Skills
- redesigning Skill Development Curve
- redesigning the Problem-Solving Engine
- making the homepage more flashy, colorful, animated, or developer-template-like

## Next Portfolio Priority

The homepage is no longer the main bottleneck.

The next priority is the public Odoo ERP Analytics case study page, because the homepage now routes visitors there as the strongest proof of the portfolio positioning.

The case study page should prove the homepage promise by showing:

- the business problem,
- why the ERP/reporting situation was difficult,
- how the business flow was mapped,
- how ERP fields, statuses, references, and unusual cases were reviewed,
- how scattered transactions became management-ready views,
- what validation or review logic was used,
- where AI-assisted development accelerated execution,
- and what this demonstrates about Fauzan's judgment and thinking.
