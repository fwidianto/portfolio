# Homepage Odoo Flagship Evidence

Status: Accepted v1 / frozen except fixes

This document records the accepted homepage direction for the Odoo ERP Analytics flagship section.

## Purpose

The section should make visitors understand that Odoo ERP Analytics is the clearest homepage proof of how Fauzan thinks and works.

It should not feel like a normal project card.

## Accepted Public Wording

Flagship Case Study

Odoo ERP Analytics

A case study of how I turned scattered ERP transactions into management-ready views.

In this project, I mapped how sales, purchasing, production, delivery, invoicing, and payment data connect in Odoo. Then I reviewed the business logic behind the data and built dashboard views that help teams see order status, issues, insights, and follow-up points more clearly.

## Accepted Route

Scattered ERP transactions -> Reliable business logic -> Management-ready views

## Accepted Proof Pillars

1. Understand the business flow
2. Check the data logic
3. Turn data into management-ready views

## Accepted Layout

Left side: Odoo badge, label, title, explanation, CTA, public-safe note.

Right side: How the work moves visual route.

Bottom row: three proof pillar cards.
