# Homepage Currently Building

Status: Active source of truth

This document defines a future homepage section that shows the portfolio is alive.

## Purpose

Currently Building should signal ongoing learning and execution without making the portfolio feel unfinished.

It should answer:

- What is Fauzan actively improving?
- What business-system question is being explored?
- What evidence is becoming stronger?
- What changed recently?

## Possible Signals

The section may show selected signals such as:

- latest portfolio update,
- latest experiment,
- current project,
- current reading or learning note,
- recent GitHub activity,
- current case-study improvement.

Use only signals that are public-safe and relevant to the portfolio story.

## Content Rules

Currently Building should be concise. It should not become a status feed or personal journal.

Each item should connect to one of these:

- business understanding,
- systems thinking,
- practical solution-building,
- AI-assisted execution,
- case-study evidence,
- portfolio experience improvement.

## What to Avoid

Avoid:

- showing too many updates,
- exposing private work,
- making incomplete work look like a defect,
- using activity as a substitute for evidence,
- publishing implementation details with no visitor value.

## Implementation Boundary

This is a concept document only. Do not implement the section until a future task explicitly requests it.
