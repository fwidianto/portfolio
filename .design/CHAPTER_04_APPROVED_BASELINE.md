## Approved operating sequence

The core business spine is:

`Customer Need -> Quote -> Procure -> Make -> Deliver -> Bill -> Collect`

Motion rules:

- one continuous luminous amber pulse;
- no teleporting;
- each stage activates only when the pulse reaches it;
- responsibilities appear only when the operating chain creates the reason for them.

Approved supporting logic:

- `Quote` -> Finance;
- `Procure` -> Suppliers;
- `Make` -> Operations + People;
- `Deliver` -> Administration;
- `Bill` -> Finance;
- `Collect` -> Cash Control.

`Make` remains the dominant physical / engineering beat.
