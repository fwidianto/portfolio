# Shared Frontend Specialist Pilot

**Status:** Ready for one controlled local run  
**Primary skill:** `$shared-frontend-visualization-specialist`  
**Branch:** `agent/portfolio-skill-experiment`

## Purpose

Test whether the shared Frontend & Visualization Specialist can execute the already approved representative homepage task with less drift, clearer stopping behavior, and better visible evidence than a normal general-agent run.

This pilot does not authorize a full homepage redesign, deployment, or continuation into another milestone.

## Start command

From a new Codex session opened at the portfolio repository root:

```text
$shared-frontend-visualization-specialist

Read `AGENTS.md` and every document in its Read First list.
Then read:
- `.design/homepage-v2-skill-experiment/DESIGN_BRIEF.md`
- `.design/homepage-v2-skill-experiment/SHARED_SPECIALIST_PILOT.md`

Execute only the delegation packet below.
Do not choose another milestone, broaden scope, deploy, merge, or perform an independent final review of your own work.
```
