# Chapter 02 Animation Reference Pack v1

## Purpose

This pack defines the **motion art direction** for Chapter 02 of the new portfolio.

It exists because the earlier Chapter 02 prototype became too text-heavy and too dependent on cards / panels with only small animations. The desired experience is the opposite:

> **Animation is the storytelling. Text provides only the minimum context needed to understand the impression.**

The website should feel like a sequence of evolving visual experiences rather than an article, résumé timeline, or dashboard.

# Core animation principle

## One mini-phase = one idea + one dominant animation + very little text.

Do not build the experience as:
`heading → paragraph → cards → tiny animation`

Prefer:
`visual event → transformation → short factual cue → next visual event`

The visitor should understand the story primarily from motion.

---

# Text budget

For most mini-phases, visible copy should be limited to:

- year / place;
- one short scene title;
- at most one concise contextual sentence when genuinely necessary.

Avoid explanatory paragraphs.

Do not display internal design notes such as:
- "motion";
- "composition";
- "exit";
- "centerpiece";
- "no airplane animation";
- "keep copy factual";
- "resolved, not triumphalist";
- "approved v2";
- implementation instructions.

Those belong in design documentation only.

# Visual language

Preserve:
- near-black / charcoal background;
- warm off-white editorial typography;
- deep orange / burnt-red signal;
- restrained glow;
- generous negative space;
- documentary real photography;
- technical traces that explain motion.

Reduce:
- telemetry UI;
- terminal aesthetics;
- boxed cards;
- dashboard framing;
- long paragraphs;
- decorative technical labels.

The Chapter should progressively move away from astronomy:

`Hero astronomy → academic atmosphere → engineering abstractions → industrial documentary → Tokyo research → focused engineering workbench`

---

# Implementation behavior

The existing Chapter 02 prototype is exploratory.

Do not throw away working factual asset integration or useful code automatically.

However, the **motion choreography should be redesigned around these keyframes**.

Layout should follow motion, rather than placing content into fixed cards and then adding animation afterward.

Build one mini-phase at a time and render it before moving to the next major sequence.

---

# Review rule

A mini-phase passes when:
1. the dominant visual idea is understandable without reading a paragraph;
2. motion communicates the transition or activity;
3. text remains secondary;
4. it feels connected to the previous and next mini-phase;
5. real evidence is used whenever factual imagery is shown.
