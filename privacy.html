Privacy Policy

Personal Gmail reader · last updated 6 November 2026

This policy covers a private Gmail reader operated by Fauzan Widianto. It is registered with Google as the OAuth application “OpenCode Google Sheets” and is used by its owner only. It is not offered as a public service and has no other users.

What the application accesses

With the owner’s explicit consent, the application requests a single Google permission:

https://www.googleapis.com/auth/gmail.readonly

This grants read-only access to Gmail messages. The application cannot send, delete, modify, or label mail.

How the data is used

Message content is read in order to summarise incoming mail, identify items that need a reply, and prepare draft text for the owner to review. Processing runs on equipment the owner controls. Summaries and alerts may be delivered to messaging channels the owner configures, such as WhatsApp or Telegram.

What is not done with the data

  • Gmail data is not sold or rented.
  • Gmail data is not used for advertising or profiling.
  • Gmail data is not shared beyond the processing providers required to operate the workflow, and those providers are bound by their own API data-use terms.

Storage and retention

Retrieved message records and generated summaries are kept in the owner’s local files so the workflow can resume without re-reading the mailbox. The owner can delete them at any time; deleting them does not affect the mailbox itself.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking the grant, or deleting the stored OAuth credentials on the owner’s machine, ends all access immediately.

Limited Use

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
