THE BUSINESS PROBLEM

The Service Division had been profitable for years. That result did not reveal how much each Full Maintenance Contract contributed.

My analysis connected machine utilization, complete maintenance packages, wrench man-hours, mechanic locations and contract costs. Some maintenance-only estimates left limited room for unexpected repairs.

This scene reconstructs that reasoning with synthetic examples. It does not reproduce company financial results or manufacturer maintenance instructions.

The model uses 8 hours × 22 days = 176 regular hours per mechanic. Capacity is pooled by month. Crew and job-duration constraints are checked, but the model does not create a day-by-day dispatch plan.

Fixed payroll is allocated by reserved regular hours / 176. The remaining payroll stays in the unallocated pool. Overtime uses an explicit synthetic hourly cost and a per-person cap. Shared overhead is an editable planning assumption.

A repair is an optional sensitivity test. Downtime is disclosed separately; it does not automatically reduce the utilization forecast or create an invented contractual penalty.
